# Laboratory-VII

Design and evaluation of a proton shielding system for tumor tissue irradiation using PHITS Monte Carlo simulations.

## Project Description

This project focuses on the computational modeling and analysis of proton irradiation in biological geometries incorporating tumor tissue. Using the PHITS Monte Carlo particle transport code, we simulate radiation interactions and track dose deposition across heterogeneous tissue media to optimize customized shielding configurations.

The primary objective is to optimize energy delivery to target tumor volumes by extending the Spread-Out Bragg Peak (SOBP) and maximizing dose homogeneity within the malignancy, while minimizing radiation exposure to adjacent healthy tissues and critical organs at risk.
